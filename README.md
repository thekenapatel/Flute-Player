# 🎶 Flute Player

An interactive **flute-playing web app** built with **JavaScript**, **HTML**, and **CSS**. <br/>
Play soothing flute notes with your keyboard or on-screen buttons — perfect for fun, relaxation, or musical experimentation!

---

## 🎧 Live Demo

[Try Flute Player](https://thekenapatel.github.io/Flute-Player/)  

---

## ✨ Features

- 🎹 Play flute notes using your **keyboard**
- 🖱️ Click on **on-screen buttons** to play notes
- 🔊 Realistic flute sound effects
- 🎨 Clean, responsive UI
- 💡 Lightweight and fast

---

## 🛠️ Tech Stack

- **HTML**
- **CSS**
- **JavaScript**
